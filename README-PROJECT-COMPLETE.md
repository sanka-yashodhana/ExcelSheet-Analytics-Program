## ?? Getting Started

### Prerequisites
- Node.js & npm (for frontend)
- .NET 8 SDK (for backend)
- SQL Server (for database)

### Installation

**Backend:**
```bash
cd C:\Users\sanka\source\repos\EmployeeExcelAnalytics
dotnet restore
dotnet build
dotnet run
```

**Frontend:**
```bash
cd frontend
npm install
npm start
```

### Access
- Backend API: `http://localhost:5239`
- Frontend App: `http://localhost:4200`
